# Week 01 Plan

## Main goal this week
The goal of the first week is simply to make a general base for the project with MVP being a simple setup with Razor-pages with a potential database setup in PostgreSQL and generally understand web structures.


## Why this week matters

This week creates the general "startup" and defines new important technology and connection to the app. Secondly it refreshes the theory of how webservers and the internet works.

## Course focus this week

### 1. Project Course

Main focus:

- Create a general setup for the project.
- Razor pages 
- Database solution


This course matters this week because:
It sets the base of the project, with a potential database solution and some general classes to display information about products on razor pages.

### 2. Essential Development Concepts & Applied Technologies

Main focus:

- Refresh essential of terms in local vs deployed settings
- Find ASP.NET Core apps and find/inspect configurations
- Create Environments_Notes.md

This course matters this week because:
It gives a sense of ASP.NET Core - it's structures and pipelines.

### 3. Developer Concepts Summation

Main focus:
- Refreshing how browser to server pipeline works
- Review status codes
- Connect principals to main project.

This course matters this week because:
It will help connect past knowledge to new project, and be a great "refresher".

### 4. General Real-World Technologies

Main focus:

- Refresh general DevOps principlas - monitoring, logging, CI/CD, cache, object storage.
- Follow user requests through realistic systems
- Sketching architectures

This course matters this week because:
It connects understanding of real world application and technologies to their deeper functionality and purpose.
